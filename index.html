Clerk Authentication Integration Guide

SkyRL's workspace is structured to support seamless user authentication via Clerk. Because this is a frontend-first static repository optimized for GitHub Pages, authentication is currently in placeholder demo mode.

Required Files to Connect Clerk:

  • Include the Clerk JavaScript frontend SDK script in portal.html.
  • Configure your publishable key in environment variables (VITE_CLERK_PUBLISHABLE_KEY or equivalent).
  • Initialize Clerk inside portal.js to mount user profile buttons and session guards.
// Example Clerk initialization snippet for future backend connection
import { Clerk } from "@clerk/clerk-js";

const clerkPubKey = process.env.VITE_CLERK_PUBLISHABLE_KEY;
const clerk = new Clerk(clerkPubKey);
await clerk.load();

if (clerk.user) {
    document.getElementById("auth-user").innerText = clerk.user.fullName;
}
